\# 🛡️ Network Intrusion Detection System



A machine learning-based network intrusion detection system that analyzes network traffic and classifies connections as \*\*Normal\*\* or \*\*Attack\*\*.



\## 📌 Project Overview



This project uses machine learning techniques to detect potential cyberattacks in network traffic. The system was developed using the KDD network intrusion detection dataset and implements classification models to identify suspicious network connections.



\## 🎯 Objectives



\- Preprocess network traffic data

\- Select relevant features for classification

\- Train machine learning models

\- Compare Decision Tree and Random Forest classifiers

\- Evaluate model performance

\- Provide a simple interface for predicting whether a network connection is Normal or an Attack



\## 🧠 Machine Learning Models



\### Decision Tree

A tree-based classification algorithm used to learn decision rules from network traffic features.



\### Random Forest

An ensemble learning algorithm that combines multiple decision trees to improve classification performance and robustness.



\## 📊 Dataset



The project uses the \*\*KDD network intrusion detection dataset\*\*, containing network connection records with numerical and categorical features.



The dataset includes features related to:



\- Network protocols

\- Services

\- Connection flags

\- Network traffic statistics

\- Host-based statistics



\## ⚙️ Methodology



1\. Data preprocessing

2\. Encoding categorical features

3\. Feature selection

4\. Model training

5\. Model evaluation

6\. Prediction through a Streamlit web interface
